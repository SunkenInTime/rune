- **`App::on_close_request` lets an app refuse a close the user asked for.** It runs before the window hides or closes for its close button, Alt+F4, the window manager's Close and ⌘W (`CloseRequest::Window`), and on macOS for Quit from a menu or the Dock (`CloseRequest::Quit`, every window asked in turn), and returns whether to go ahead; false keeps the window up so an editor can show its unsaved-changes alert, then `Tx::close_window()` or `Tx::quit()` closes without asking again. Closes the app asks for, `AppHandle::close`, and logout, shutdown or a Windows session end never ask. `WindowSpec::on_close_request` sets it per window; scripts ask with `{"close": true}`. Apps without the hook close as before.
