- **File dialogs: `FileDialogOptions::prompt` and `message`.** The default button's label and a line explaining the dialog, set with `.prompt(..)` and `.message(..)`: both on macOS panels, the prompt as the XDG portal's `accept_label` on Linux, neither on Windows. `--tree` shows them. `FileDialogOptions` gained the two fields, so a literal that names every field needs `..Default::default()`.
